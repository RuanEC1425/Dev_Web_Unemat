Sobre o Projeto IronLab

Este catálogo interativo foi desenvolvido como aplicação prática de Front-end utilizando HTML5 semântico, estilização com CSS3 e Bootstrap 5, além de consumo assíncrono de dados JSON com JavaScript puro (ES6+ Fetch API).

Especificações Técnicas

  • Layout 100% Responsivo (Mobile-First)
  • Dupla Requisição AJAX (Listagem + Detalhes)
  • Filtro Combinado em Tempo Real
  • HTML Semântico e Acessibilidade (WAI-ARIA)
